# Plano 2 — `packages/ai` · Plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam checkbox (`- [ ]`) para acompanhamento.

**Goal:** criar `@meu-sommelier/ai` com as portas `Sommelier`, `ModeloLLM` e `BuscaPrecos`, os adaptadores Anthropic e OpenAI-compatível, a busca de preços, os fakes, a configuração por variáveis de ambiente e as ferramentas manuais de contrato e de avaliação.

**Architecture:** `SommelierPadrao` orquestra as portas: gera a ficha com um `ModeloLLM` e, se der certo, busca o preço com uma `BuscaPrecos`, dentro do prazo total. Todo `gerarJson` passa por `gerarComRetentativa`, que valida com zod e faz uma nova tentativa enviando o erro. Os adaptadores só convertem o pedido para o formato de cada provedor. `carregarConfigIA` valida as variáveis na subida e `criarSommelier` monta tudo.

**Tech Stack:** `@anthropic-ai/sdk` (0.131+, `client.beta.messages.create` com `betaZodOutputFormat`), `openai` (7.x, `chat.completions`), zod 4, Vitest, MSW 3 (`msw/node`), tsx (scripts), Tavily (API de busca).

**Spec:** `docs/superpowers/specs/2026-10-05-sommelier-mvp-design.md` (seções 4, 6 e 7). Plano anterior: `docs/superpowers/plans/2026-10-05-plano-1-monorepo-core.md`.

### Decisões deste plano (desvios ou detalhes que a spec não fixa)

Estas decisões precisam do ok do usuário na revisão do plano:

1. **`gerarJson` recebe `tipo` e devolve `usos: UsoIA[]`**, em vez de um único `uso`. A nova tentativa gera duas chamadas, e as duas precisam ser registradas em `uso_ia`. Pelo mesmo motivo, `BuscaPrecos` devolve `usos` e recebe `timeoutMs`, já que o prazo de 45 s inclui o preço.
2. **`core` ganha `FichaVinhoCamposSchema` e `validarRegrasFicha`.** O zod 4 proíbe `.omit()` em schema com refinamentos, e o `ai` precisa da ficha sem os campos de preço para pedir à IA.
3. **`fichaPorNome` usa o modelo de `IA_ROTULO`.** A spec só tem `IA_ROTULO` e `IA_PRATO`, e gerar a ficha é a mesma tarefa com ou sem foto.
4. **`IA_PRECO_BUSCA=api-busca` extrai os preços com o modelo de `IA_PRATO`.** Assim não é preciso uma variável nova.
5. **O modo `fake` vale para tudo ou para nada.** Se `IA_ROTULO` ou `IA_PRATO` for `fake`, os dois precisam ser `fake` e `IA_PRECO_BUSCA` precisa ser `fake` ou `nenhuma`. Nesse modo, `criarSommelier` devolve o `FakeSommelier` do E2E.
6. **`effort: "medium"` explícito.** É o padrão do Opus 5.5, mas fica escrito para não mudar sem querer.
7. **Busca web custa US$ 0,01 por busca** (US$ 10 a cada 1.000). Preço de tabela em 2026-10; conferir na página de preços da Anthropic antes de confiar nos limites de custo.
8. **A correção da nova tentativa vai numa nova mensagem de usuário**, com a resposta anterior citada no texto. Não é reenviado nenhum turno de assistente, o que evita problemas com os blocos de raciocínio do Opus 5.5.
9. **Imagens aceitas: `image/jpeg`, `image/png` e `image/webp`**, como na seção 6 da spec.
10. **Variáveis de ambiente vazias (`CHAVE=`) contam como ausentes.**

## Global Constraints

- `ai` depende só de `@meu-sommelier/core` entre os pacotes do projeto (`ai → core`).
- Modelo padrão: `claude-opus-5-5`. Toda chamada Anthropic usa `betas: ["server-side-fallback-2026-07-01"]` + `fallbacks: "default"`.
- Saída estruturada da Anthropic via `output_config.format` gerado por `betaZodOutputFormat(schema)`. O helper remove restrições que a API não aceita (`minLength`, `minimum`…), e o zod revalida tudo depois.
- Busca de preço Anthropic: `web_search_20260209`, `max_uses: 3`, `user_location` `{ type: "approximate", country: "BR", timezone: "America/Sao_Paulo" }`.
- Timeouts: **45 s** para rótulo/nome, **incluindo o preço**, e **20 s** para prato. O tempo é medido com `AbortSignal.timeout`, que cobre as retentativas do SDK.
- Todo `gerarJson` valida com zod e faz **1 nova tentativa** com o erro; se falhar de novo, lança `ErroIA("indisponivel")`. O SDK faz até 2 retentativas para 429/5xx/rede.
- Prompts em `packages/ai/prompts/*.md`, em pt-BR, tratando o conteúdo do usuário como dado.
- **Nenhum teste automatizado chama IA real nem a internet.** Todo arquivo que usa MSW liga o servidor com `onUnhandledRequest: "error"`.
- Commits e push **só com aceite explícito do usuário**.

## Review Focus

1. **IA responde o JSON dentro de cercas ```` ```json ```` ou com texto antes**, o que é comum em provedores OpenAI-compatíveis sem `json_schema`. O JSON precisa ser aproveitado em vez de virar falha. → teste na Tarefa 3.
2. **Provedor lento**: o prazo de 45 s inclui o preço. A busca só recebe o tempo que sobrou; se não sobrar nada, a ficha volta sem preço em vez de estourar o tempo. → teste na Tarefa 8.
3. **Preço devolvido como texto** (`"R$ 1.234,56"`) ou fonte com link não-http(s): a busca vira `{ ok: false }` e nunca derruba a leitura do rótulo. → testes nas Tarefas 4 e 7.
4. **Variável de ambiente vazia no Railway** (`ANTHROPIC_API_KEY=`): tratada como ausente, com mensagem clara na subida. → teste na Tarefa 10.
5. **IA de sugestão inventa ou repete `itemId`**: os ids são filtrados, e se nada sobrar `semBoaOpcao` vem preenchido. → teste na Tarefa 8.

// Preços de tabela da Anthropic em 2026-10, em US$ por milhão de tokens.
const PRECO_POR_MTOK: Record<string, { entrada: number; saida: number }> = {
  "claude-opus-5-5": { entrada: 4, saida: 20 },
  "claude-opus-5": { entrada: 5, saida: 25 },
  "claude-opus-4-8": { entrada: 5, saida: 25 },
  "claude-sonnet-5-5": { entrada: 2, saida: 10 },
  "claude-haiku-4-5": { entrada: 1, saida: 5 },
};

export const USD_POR_BUSCA_WEB = 0.01;

export function custoAnthropicUsd(
  modelo: string,
  tokensEntrada: number,
  tokensSaida: number,
  buscasWeb = 0,
): number | null {
  const preco = PRECO_POR_MTOK[modelo];
  if (!preco) return null;
  return (
    (tokensEntrada * preco.entrada + tokensSaida * preco.saida) / 1_000_000 +
    buscasWeb * USD_POR_BUSCA_WEB
  );
}

import { z } from "zod";
import { ErroIA, type RespostaJson, type UsoIA } from "./tipos";

export interface Tentativa {
  texto: string;
  uso: UsoIA;
}

export interface Correcao {
  respostaAnterior: string;
  erro: string;
}

export function extrairJson(texto: string): string {
  const inicio = texto.indexOf("{");
  const fim = texto.lastIndexOf("}");
  return inicio >= 0 && fim > inicio ? texto.slice(inicio, fim + 1) : texto.trim();
}

export function validarJson<T>(
  texto: string,
  schema: z.ZodType<T>,
): { ok: true; dados: T } | { ok: false; erro: string } {
  let bruto: unknown;
  try {
    bruto = JSON.parse(extrairJson(texto));
  } catch {
    return { ok: false, erro: "a resposta não é um JSON válido" };
  }
  const resultado = schema.safeParse(bruto);
  return resultado.success
    ? { ok: true, dados: resultado.data }
    : { ok: false, erro: z.prettifyError(resultado.error) };
}

export function mensagemCorrecao(c: Correcao): string {
  return [
    "Sua resposta anterior foi:",
    c.respostaAnterior,
    "",
    "Ela não passou na validação:",
    c.erro,
    "",
    "Responda de novo, somente com o JSON corrigido.",
  ].join("\n");
}

export async function gerarComRetentativa<T>(
  schema: z.ZodType<T>,
  chamar: (correcao: Correcao | null) => Promise<Tentativa>,
): Promise<RespostaJson<T>> {
  const usos: UsoIA[] = [];
  let correcao: Correcao | null = null;

  for (let tentativa = 0; tentativa < 2; tentativa++) {
    let resposta: Tentativa;
    try {
      resposta = await chamar(correcao);
    } catch (erro) {
      if (erro instanceof ErroIA) {
        throw new ErroIA(erro.motivo, erro.message, [...usos, ...erro.usos], { cause: erro.cause });
      }
      throw new ErroIA("indisponivel", "falha ao chamar o provedor de IA", usos, { cause: erro });
    }
    usos.push(resposta.uso);
    const validacao = validarJson(resposta.texto, schema);
    if (validacao.ok) return { dados: validacao.dados, usos };
    correcao = { respostaAnterior: resposta.texto, erro: validacao.erro };
  }
  throw new ErroIA("indisponivel", "a IA respondeu um JSON inválido duas vezes", usos);
}

    readonly suportaImagem = true,
  ) {}

  async gerarJson<T>(pedido: PedidoJson<T>): Promise<RespostaJson<T>> {
    this.pedidos.push(pedido as unknown as PedidoJson<unknown>);
    if (pedido.imagem && !this.suportaImagem) {

      const proxima = this.respostas.shift();
      if (proxima === undefined) throw new Error("FakeLLM sem respostas na fila");
      if (proxima instanceof Error) throw proxima;

import Anthropic from "@anthropic-ai/sdk";
import { betaZodOutputFormat } from "@anthropic-ai/sdk/helpers/beta/zod";
import { custoAnthropicUsd } from "./custos";
import { gerarComRetentativa, mensagemCorrecao } from "./retentativa";
import {
  ErroIA,
  type ModeloLLM,
  type PedidoJson,
  type RespostaJson,
  type TipoUso,
  type UsoIA,
} from "./tipos";

export const BETA_FALLBACK = "server-side-fallback-2026-07-01";

export type Esforco = "low" | "medium" | "high";

export interface OpcoesAnthropic {
  apiKey: string;
  modelo: string;
  esforco?: Esforco;
  maxRetries?: number;
  baseURL?: string;
}

export function usoAnthropic(tipo: TipoUso, modelo: string, usage: Anthropic.Beta.BetaUsage): UsoIA {
  const tokensEntrada =
    usage.input_tokens +
    (usage.cache_creation_input_tokens ?? 0) +
    (usage.cache_read_input_tokens ?? 0);
  const buscasWeb = usage.server_tool_use?.web_search_requests ?? 0;
  return {
    tipo,
    provedor: "anthropic",
    modelo,
    tokensEntrada,
    tokensSaida: usage.output_tokens,
    custoUsd: custoAnthropicUsd(modelo, tokensEntrada, usage.output_tokens, buscasWeb),
  };
}

export function textoDaResposta(resposta: Anthropic.Beta.BetaMessage): string {
  return resposta.content.flatMap((bloco) => (bloco.type === "text" ? [bloco.text] : [])).join("");
}

export class AnthropicLLM implements ModeloLLM {
  readonly suportaImagem = true;
  private readonly cliente: Anthropic;

  constructor(private readonly opcoes: OpcoesAnthropic) {
    this.cliente = new Anthropic({
      apiKey: opcoes.apiKey,
      baseURL: opcoes.baseURL,
      maxRetries: opcoes.maxRetries ?? 2,
    });
  }

  gerarJson<T>(pedido: PedidoJson<T>): Promise<RespostaJson<T>> {
    const formato = betaZodOutputFormat(pedido.schema);
    const sinal = AbortSignal.timeout(pedido.timeoutMs);
    const conteudo: Anthropic.Beta.BetaContentBlockParam[] = [];
    if (pedido.imagem) {
      conteudo.push({
        type: "image",
        source: {
          type: "base64",
          media_type: pedido.imagem.mime,
          data: Buffer.from(pedido.imagem.bytes).toString("base64"),
        },
      });
    }
    conteudo.push({ type: "text", text: pedido.texto });

    return gerarComRetentativa(pedido.schema, async (correcao) => {
      const mensagens: Anthropic.Beta.BetaMessageParam[] = [{ role: "user", content: conteudo }];
      if (correcao) mensagens.push({ role: "user", content: mensagemCorrecao(correcao) });

      const resposta = await this.cliente.beta.messages.create(
        {
          model: this.opcoes.modelo,
          max_tokens: 16_000,
          betas: [BETA_FALLBACK],
          fallbacks: "default",
          system: pedido.instrucoes,
          output_config: { effort: this.opcoes.esforco ?? "medium", format: formato },
          messages: mensagens,
        },
        { signal: sinal },
      );
      const uso = usoAnthropic(pedido.tipo, resposta.model, resposta.usage);
      if (resposta.stop_reason === "refusal") {
        throw new ErroIA("indisponivel", "a IA recusou o pedido", [uso]);
      }
      return { texto: textoDaResposta(resposta), uso };
    });
  }
}

import { ErroIA, type ModeloLLM, type PedidoJson, type RespostaJson, type UsoIA } from "./tipos";

export interface OpcoesOpenAICompat {
  apiKey: string;
  baseURL: string;
  modelo: string;
  usarJsonSchema: boolean;
  suportaImagem: boolean;
  maxRetries?: number;
}

export class OpenAICompativelLLM implements ModeloLLM {
  readonly suportaImagem: boolean;
  private readonly cliente: OpenAI;

  constructor(private readonly opcoes: OpcoesOpenAICompat) {
    this.suportaImagem = opcoes.suportaImagem;
    this.cliente = new OpenAI({
      apiKey: opcoes.apiKey,
      baseURL: opcoes.baseURL,
      maxRetries: opcoes.maxRetries ?? 2,
    });
  }

  async gerarJson<T>(pedido: PedidoJson<T>): Promise<RespostaJson<T>> {
    if (pedido.imagem && !this.suportaImagem) {
      throw new ErroIA("indisponivel", `o modelo ${this.opcoes.modelo} não aceita imagem`);
    }
    const jsonSchema = z.toJSONSchema(pedido.schema) as Record<string, unknown>;
    const sistema = this.opcoes.usarJsonSchema
      ? pedido.instrucoes
      : `${pedido.instrucoes}\n\nResponda somente com um objeto JSON que siga este JSON Schema:\n${JSON.stringify(jsonSchema)}`;
    const conteudo: OpenAI.Chat.ChatCompletionContentPart[] = [{ type: "text", text: pedido.texto }];
    if (pedido.imagem) {
      const base64 = Buffer.from(pedido.imagem.bytes).toString("base64");
      conteudo.push({ type: "image_url", image_url: { url: `data:${pedido.imagem.mime};base64,${base64}` } });
    }
    const sinal = AbortSignal.timeout(pedido.timeoutMs);

    return gerarComRetentativa(pedido.schema, async (correcao) => {
      const mensagens: OpenAI.Chat.ChatCompletionMessageParam[] = [
        { role: "system", content: sistema },
        { role: "user", content: conteudo },
      ];
      if (correcao) mensagens.push({ role: "user", content: mensagemCorrecao(correcao) });

      const parametros: OpenAI.Chat.ChatCompletionCreateParamsNonStreaming = {
        model: this.opcoes.modelo,
        messages: mensagens,
      };
      if (this.opcoes.usarJsonSchema) {
        parametros.response_format = {
          type: "json_schema",
          json_schema: { name: "resposta", schema: jsonSchema, strict: false },
        };
      }
      const resposta = await this.cliente.chat.completions.create(parametros, { signal: sinal });
      const uso: UsoIA = {
        tipo: pedido.tipo,
        provedor: "openai-compat",
        modelo: resposta.model || this.opcoes.modelo,
        tokensEntrada: resposta.usage?.prompt_tokens ?? 0,
        tokensSaida: resposta.usage?.completion_tokens ?? 0,
        custoUsd: null,
      };
      return { texto: resposta.choices[0]?.message.content ?? "", uso };

type PedidoPreco = Parameters<BuscaPrecos["buscar"]>[0];

export function descreverVinho(nome: string, safra: number | null): string {
  return `<vinho>${nome}</vinho>\n<safra>${safra ?? "sem safra (NV)"}</safra>`;
}

function resultado(preco: PrecoIA, usos: UsoIA[]): ResultadoBuscaPrecos {
  const emCentavos = precoParaCentavos(preco);
  return emCentavos ? { ok: true, ...emCentavos, usos } : { ok: false, usos };
}

export class SemBuscaPrecos implements BuscaPrecos {
  async buscar(): Promise<ResultadoBuscaPrecos> {
    return { ok: false, usos: [] };
  }

export class BuscaPrecosAnthropic implements BuscaPrecos {
  private readonly cliente: Anthropic;

  constructor(private readonly opcoes: Omit<OpcoesAnthropic, "esforco">) {
    this.cliente = new Anthropic({
      apiKey: opcoes.apiKey,
      baseURL: opcoes.baseURL,
      maxRetries: opcoes.maxRetries ?? 2,
    });
  }

  async buscar({ nome, safra, timeoutMs }: PedidoPreco): Promise<ResultadoBuscaPrecos> {
    let resposta: Anthropic.Beta.BetaMessage;
    try {
      resposta = await this.cliente.beta.messages.create(
        {
          model: this.opcoes.modelo,
          max_tokens: 16_000,
          betas: [BETA_FALLBACK],
          fallbacks: "default",
          system: carregarPrompt("preco"),
          output_config: { effort: "medium" },
          tools: [
            {
              type: "web_search_20260209",
              name: "web_search",
              max_uses: 3,
              user_location: { type: "approximate", country: "BR", timezone: "America/Sao_Paulo" },
            },
          ],
          messages: [{ role: "user", content: descreverVinho(nome, safra) }],
        },
        { signal: AbortSignal.timeout(timeoutMs) },
      );
    } catch {
      return { ok: false, usos: [] };
    }

    const usos = [usoAnthropic("preco", resposta.model, resposta.usage)];
    const buscaFalhou = resposta.content.some(
      (bloco) => bloco.type === "web_search_tool_result" && !Array.isArray(bloco.content),
    );
    if (resposta.stop_reason !== "end_turn" || buscaFalhou) return { ok: false, usos };

    const ultimoTexto = resposta.content.findLast((bloco) => bloco.type === "text");
    if (!ultimoTexto || ultimoTexto.type !== "text") return { ok: false, usos };
    const validacao = validarJson(ultimoTexto.text, PrecoIASchema);
    return validacao.ok ? resultado(validacao.dados, usos) : { ok: false, usos };
  }
}

export const URL_TAVILY = "https://api.tavily.com/search";

const ResultadosBuscaSchema = z.object({
  results: z.array(z.object({ title: z.string(), url: z.string(), content: z.string() })),
});

export interface OpcoesApiBusca {
  tavilyApiKey: string;
  llm: ModeloLLM;
  url?: string;
}

export class BuscaPrecosApiBusca implements BuscaPrecos {
  constructor(private readonly opcoes: OpcoesApiBusca) {}

  async buscar({ nome, safra, timeoutMs }: PedidoPreco): Promise<ResultadoBuscaPrecos> {
    const prazo = Date.now() + timeoutMs;
    let resultados: z.infer<typeof ResultadosBuscaSchema>["results"];
    try {
      const resposta = await fetch(this.opcoes.url ?? URL_TAVILY, {
        method: "POST",
        headers: {
          "content-type": "application/json",
          authorization: `Bearer ${this.opcoes.tavilyApiKey}`,
        },
        body: JSON.stringify({
          query: `${nome} ${safra ?? ""} vinho preço comprar`.replace(/\s+/g, " ").trim(),
          max_results: 8,
          search_depth: "basic",
        }),
        signal: AbortSignal.timeout(timeoutMs),
      });
      if (!resposta.ok) return { ok: false, usos: [] };
      const corpo = ResultadosBuscaSchema.safeParse(await resposta.json());
      if (!corpo.success || corpo.data.results.length === 0) return { ok: false, usos: [] };
      resultados = corpo.data.results;
    } catch {
      return { ok: false, usos: [] };
    }

    try {
      const { dados, usos } = await this.opcoes.llm.gerarJson({
        tipo: "preco",
        instrucoes: carregarPrompt("preco"),
        texto: `${descreverVinho(nome, safra)}\n<resultados_busca>${JSON.stringify(resultados)}</resultados_busca>`,
        schema: PrecoIASchema,
        timeoutMs: Math.max(1, prazo - Date.now()),
      });
      return resultado(dados, usos);
    } catch (erro) {
      return { ok: false, usos: erro instanceof ErroIA ? erro.usos : [] };
    }
  }
}

import {
  anoEm,
  FichaVinhoSchema,
  filtrarSugestoes,
  relogioSistema,
  type Relogio,
} from "@meu-sommelier/core";
import { carregarPrompt } from "./prompts";
import {
  completarFicha,
  RespostaFichaSchema,
  RespostaSugestaoSchema,
  type RespostaFicha,
} from "./respostas";
import {
  ErroIA,
  type BuscaPrecos,
  type Imagem,
  type ItemResumo,
  type ModeloLLM,
  type RespostaJson,
  type ResultadoFicha,
  type ResultadoSugestao,
  type Sommelier,
} from "./tipos";

export const TIMEOUT_FICHA_MS = 45_000;
export const TIMEOUT_PRATO_MS = 20_000;
export const ESTILO_SEM_SUGESTAO = "Nenhuma garrafa da adega combina bem com este prato.";

export interface DependenciasSommelier {
  llmRotulo: ModeloLLM;
  llmPrato: ModeloLLM;
  buscaPrecos: BuscaPrecos;
  relogio?: Relogio;
}

export class SommelierPadrao implements Sommelier {
  private readonly relogio: Relogio;

  constructor(private readonly deps: DependenciasSommelier) {
    this.relogio = deps.relogio ?? relogioSistema;
  }

  lerRotulo(imagem: Imagem): Promise<ResultadoFicha> {
    return this.gerarFicha("rotulo", "Leia o rótulo desta foto.", imagem);
  }

  fichaPorNome(texto: string): Promise<ResultadoFicha> {
    return this.gerarFicha("nome", `<nome_do_vinho>${texto}</nome_do_vinho>`);
  }

  async sugerirParaPrato({ prato, adega }: { prato: string; adega: ItemResumo[] }): Promise<ResultadoSugestao> {
    if (adega.length === 0) return { ok: true, sugestoes: [], semBoaOpcao: null, usos: [] };
    try {
      const { dados, usos } = await this.deps.llmPrato.gerarJson({
        tipo: "prato",
        instrucoes: carregarPrompt("prato"),
        texto: `<prato>${prato}</prato>\n<adega>${JSON.stringify(adega)}</adega>`,
        schema: RespostaSugestaoSchema,
        timeoutMs: TIMEOUT_PRATO_MS,
      });
      const sugestoes = filtrarSugestoes(dados.sugestoes, adega.map((i) => i.id));
      const semBoaOpcao =
        sugestoes.length === 0
          ? (dados.semBoaOpcao ?? { estiloIdeal: ESTILO_SEM_SUGESTAO })
          : dados.semBoaOpcao;
      return { ok: true, sugestoes, semBoaOpcao, usos };
    } catch (erro) {
      if (erro instanceof ErroIA) return { ok: false, motivo: "indisponivel", usos: erro.usos };
      throw erro;
    }
  }

  private async gerarFicha(
    tipo: "rotulo" | "nome",
    texto: string,
    imagem?: Imagem,
  ): Promise<ResultadoFicha> {
    const inicio = this.relogio.agora();
    let resposta: RespostaJson<RespostaFicha>;
    try {
      resposta = await this.deps.llmRotulo.gerarJson({
        tipo,
        instrucoes: carregarPrompt(tipo),
        texto: `Ano atual: ${anoEm(inicio)}\n${texto}`,
        imagem,
        schema: RespostaFichaSchema,
        timeoutMs: TIMEOUT_FICHA_MS,
      });
    } catch (erro) {
      if (erro instanceof ErroIA) return { ok: false, motivo: "indisponivel", usos: erro.usos };
      throw erro;
    }

    const { dados, usos } = resposta;
    if (dados.status !== "ok") return { ok: false, motivo: dados.status, usos };
    if (dados.ficha === null) return { ok: false, motivo: "indisponivel", usos };
    const ficha = completarFicha(dados.ficha);

    const restante = inicio.getTime() + TIMEOUT_FICHA_MS - this.relogio.agora().getTime();
    if (restante <= 0) return { ok: true, ficha, precoConsultado: false, usos };

    const preco = await this.deps.buscaPrecos.buscar({ nome: ficha.nome, safra: ficha.safra, timeoutMs: restante });
    const todosUsos = [...usos, ...preco.usos];
    if (!preco.ok) return { ok: true, ficha, precoConsultado: false, usos: todosUsos };

    const comPreco = FichaVinhoSchema.safeParse({
      ...ficha,
      precoMinCentavos: preco.min,
      precoMaxCentavos: preco.max,
      precoFontes: preco.fontes,
      precoConsultadoEm: this.relogio.agora().toISOString(),
    });
    return comPreco.success
      ? { ok: true, ficha: comPreco.data, precoConsultado: true, usos: todosUsos }
      : { ok: true, ficha, precoConsultado: false, usos: todosUsos };
  }
}

import type { Relogio } from "@meu-sommelier/core";
import { z } from "zod";
import { AnthropicLLM } from "./anthropic";
import { BuscaPrecosAnthropic, BuscaPrecosApiBusca, SemBuscaPrecos } from "./busca-precos";
import { FakeSommelier } from "./fakes";
import { OpenAICompativelLLM } from "./openai-compat";
import { SommelierPadrao } from "./sommelier";
import type { BuscaPrecos, ModeloLLM, Sommelier } from "./tipos";

export type Provedor = "anthropic" | "openai-compat" | "fake";
export interface AlvoIA {
  provedor: Provedor;
  modelo: string;
}

const MODELO_PADRAO = "claude-opus-5-5";
const ALVO = /^(anthropic|openai-compat|fake):(.+)$/;

const alvo = (padrao: string) =>
  z
    .string()
    .default(padrao)
    .transform((valor, ctx): AlvoIA => {
      const partes = ALVO.exec(valor);
      if (!partes) {
        ctx.addIssue({
          code: "custom",
          message: `"${valor}" não está no formato provedor:modelo (provedores: anthropic, openai-compat, fake)`,
        });
        return z.NEVER;
      }
      return { provedor: partes[1] as Provedor, modelo: partes[2]! };
    });

const booleano = z
  .enum(["true", "false"])
  .default("true")
  .transform((valor) => valor === "true");

export const EnvIASchema = z
  .object({
    IA_ROTULO: alvo(`anthropic:${MODELO_PADRAO}`),
    IA_PRATO: alvo(`anthropic:${MODELO_PADRAO}`),
    IA_PRECO_BUSCA: z.enum(["anthropic", "api-busca", "nenhuma", "fake"]).default("anthropic"),
    IA_PRECO_MODELO: z.string().default(MODELO_PADRAO),
    ANTHROPIC_API_KEY: z.string().optional(),
    OPENAI_COMPAT_BASE_URL: z.url().optional(),
    OPENAI_COMPAT_API_KEY: z.string().optional(),
    OPENAI_COMPAT_JSON_SCHEMA: booleano,
    OPENAI_COMPAT_SUPORTA_IMAGEM: booleano,
    TAVILY_API_KEY: z.string().optional(),
  })
  .superRefine((e, ctx) => {
    const exigir = (campo: string, mensagem: string) =>
      ctx.addIssue({ code: "custom", path: [campo], message: mensagem });
    const provedores = [e.IA_ROTULO.provedor, e.IA_PRATO.provedor];

    if (provedores.includes("fake") || e.IA_PRECO_BUSCA === "fake") {
      const tudoFake =
        provedores.every((p) => p === "fake") &&
        (e.IA_PRECO_BUSCA === "fake" || e.IA_PRECO_BUSCA === "nenhuma");
      if (!tudoFake) {
        exigir(
          "IA_ROTULO",
          "o modo fake vale para tudo: use IA_ROTULO e IA_PRATO fake e IA_PRECO_BUSCA fake ou nenhuma",
        );
      }
      return;
    }
    if ((provedores.includes("anthropic") || e.IA_PRECO_BUSCA === "anthropic") && !e.ANTHROPIC_API_KEY) {
      exigir("ANTHROPIC_API_KEY", "ANTHROPIC_API_KEY é obrigatória quando algum provedor é anthropic");
    }
    if (provedores.includes("openai-compat")) {
      if (!e.OPENAI_COMPAT_BASE_URL) exigir("OPENAI_COMPAT_BASE_URL", "OPENAI_COMPAT_BASE_URL é obrigatória para openai-compat");
      if (!e.OPENAI_COMPAT_API_KEY) exigir("OPENAI_COMPAT_API_KEY", "OPENAI_COMPAT_API_KEY é obrigatória para openai-compat");
    }
    if (e.IA_ROTULO.provedor === "openai-compat" && !e.OPENAI_COMPAT_SUPORTA_IMAGEM) {
      exigir("IA_ROTULO", "o modelo de IA_ROTULO precisa aceitar imagem (OPENAI_COMPAT_SUPORTA_IMAGEM=false)");
    }
    if (e.IA_PRECO_BUSCA === "api-busca" && !e.TAVILY_API_KEY) {
      exigir("TAVILY_API_KEY", "TAVILY_API_KEY é obrigatória com IA_PRECO_BUSCA=api-busca");
    }
  });

export type ConfigIA = z.output<typeof EnvIASchema>;

export function carregarConfigIA(env: Record<string, string | undefined>): ConfigIA {
  const semVazios = Object.fromEntries(
    Object.entries(env).filter(([, valor]) => valor !== undefined && valor.trim() !== ""),
  );
  const resultado = EnvIASchema.safeParse(semVazios);
  if (!resultado.success) {
    throw new Error(`Configuração de IA inválida:\n${z.prettifyError(resultado.error)}`);
  }
  return resultado.data;
}

function criarLLM(alvoIA: AlvoIA, config: ConfigIA): ModeloLLM {
  switch (alvoIA.provedor) {
    case "anthropic":
      return new AnthropicLLM({ apiKey: config.ANTHROPIC_API_KEY!, modelo: alvoIA.modelo });
    case "openai-compat":
      return new OpenAICompativelLLM({
        apiKey: config.OPENAI_COMPAT_API_KEY!,
        baseURL: config.OPENAI_COMPAT_BASE_URL!,
        modelo: alvoIA.modelo,
        usarJsonSchema: config.OPENAI_COMPAT_JSON_SCHEMA,
        suportaImagem: config.OPENAI_COMPAT_SUPORTA_IMAGEM,
      });
    case "fake":
      throw new Error("o provedor fake só existe no modo fake completo");
  }
}

function criarBuscaPrecos(config: ConfigIA, llmPrato: ModeloLLM): BuscaPrecos {
  switch (config.IA_PRECO_BUSCA) {
    case "anthropic":
      return new BuscaPrecosAnthropic({ apiKey: config.ANTHROPIC_API_KEY!, modelo: config.IA_PRECO_MODELO });
    case "api-busca":
      return new BuscaPrecosApiBusca({ tavilyApiKey: config.TAVILY_API_KEY!, llm: llmPrato });
    case "nenhuma":
    case "fake":
      return new SemBuscaPrecos();
  }
}

export function criarSommelier(config: ConfigIA, opcoes: { relogio?: Relogio } = {}): Sommelier {
  if (config.IA_ROTULO.provedor === "fake") return new FakeSommelier();
  const llmRotulo = criarLLM(config.IA_ROTULO, config);
  const llmPrato = criarLLM(config.IA_PRATO, config);
  return new SommelierPadrao({
    llmRotulo,
    llmPrato,
    buscaPrecos: criarBuscaPrecos(config, llmPrato),
    relogio: opcoes.relogio,
  });
}

import { chaveDuplicata } from "@meu-sommelier/core";
import { z } from "zod";
import type { MimeImagem, ResultadoFicha } from "./tipos";

export const GabaritoSchema = z.array(
  z.object({
    arquivo: z.string().min(1),
    nome: z.string().min(1),
    safra: z.number().int().nullable(),
  }),
);
export type ItemGabarito = z.infer<typeof GabaritoSchema>[number];

const normalizar = (nome: string) => chaveDuplicata(nome, null).replace(/\|nv$/, "");

export function avaliarLeitura(
  esperado: ItemGabarito,
  resultado: ResultadoFicha,
): { acertouNome: boolean; acertouSafra: boolean; custoUsd: number } {
  const custoUsd = resultado.usos.reduce((total, uso) => total + (uso.custoUsd ?? 0), 0);
  if (!resultado.ok) return { acertouNome: false, acertouSafra: false, custoUsd };
  const lido = normalizar(resultado.ficha.nome);
  const alvo = normalizar(esperado.nome);
  return {
    acertouNome: lido.includes(alvo) || alvo.includes(lido),
    acertouSafra: resultado.ficha.safra === esperado.safra,
    custoUsd,
  };
}

const MIMES: Record<string, MimeImagem> = {
  jpg: "image/jpeg",
  jpeg: "image/jpeg",
  png: "image/png",
  webp: "image/webp",
};

export function mimeDoArquivo(arquivo: string): MimeImagem | null {
  const extensao = arquivo.split(".").pop()?.toLowerCase() ?? "";
  return MIMES[extensao] ?? null;
}
